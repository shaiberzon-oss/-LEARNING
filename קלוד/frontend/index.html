📋 Step 1 — Get a YouTube API Key (once):
Go to console.cloud.google.com → Create project → APIs & Services → Enable "YouTube Data API v3" → Credentials → Create API Key.
Then paste the key in ⚙ Settings above and save.

📋 Step 2 — Find your playlist:
Enter your YouTube Channel ID (starts with UC…) or any search term, then click Browse Playlists to see available playlists. Or paste a Playlist ID directly if you already have it.

📋 Step 1 — Create a Twitter Developer App (once):
Go to developer.twitter.com → Create project → Create App → Keys and Tokens → copy the Bearer Token.
Paste it in ⚙ Settings → Twitter Bearer Token.

📋 Step 2 — Import liked tweets:
Enter your Twitter/X username (without @) and click Import. This will pull all tweets you have liked.

📋 Step 1 — Create a Reddit App (once):
Go to reddit.com/prefs/apps → Create app → select script → fill in name and redirect (anything) → Create.
Copy the client ID (under the app name) and client secret.
Paste them in ⚙ Settings → Reddit.

📋 Step 2 — Import saved posts:
Enter your Reddit username and password. This will pull all posts and comments you have saved.

📋 How to export from LinkedIn:
LinkedIn → Me → Settings & Privacy → Data Privacy → Get a copy of your data → Select "Posts" and "Articles" → Request archive → Download ZIP (usually arrives by email within 10 min).
Upload the ZIP here — articles, posts, and saved content will be imported.

📋 How to get iPhone photos to your computer:
• iCloud: icloud.com → Photos → select photos → download
• USB: Connect iPhone → File Explorer → iPhone → Internal Storage → DCIM
• Email/WhatsApp: Send photos to yourself

Claude will read each image and extract / summarize the knowledge in it (great for screenshots of articles, notes, whiteboards).
📷
Drop photos here, or click to browse (JPG, PNG, WebP)

📋 How to export from ChatGPT:
ChatGPT → your avatar (top-right) → Settings → Data Controls → Export data → Confirm → Wait for email → Download ZIP.
Upload the ZIP or the conversations.json file inside it.
